Entry for the make.fun competition [Charm the Commuter: Forecast a City That Isn't](https://make.fun/c/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e).

`main.py` writes one line of weather for Drizzlewick — a city that does not exist — to `/output/entry.txt`:

> Drizzlewick today: light rain, 14 degrees, and the number 7 bus still only a rumour — bring a brolly, and low expectations.

Run it with:

```sh
python3 main.py
```
